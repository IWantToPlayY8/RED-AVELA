# Claims and boundaries

## Supported by this preserved run

This run supports the statement that RED AVELA independently:

- located the supplied byte-input surface;
- traced input into the relevant implementation;
- formed the correct source-level unchecked-copy hypothesis;
- generated seven candidate artifacts;
- initiated seven executions;
- observed seven nonzero status-86 results;
- declined to treat those results as sufficient confirmation; and
- ended with an explicit `inconclusive` verdict.

Separate post-run verification supports the additional statements that:

- the underlying defect was real and reachable;
- the original status-86 signal was non-specific; and
- RED's exact final candidate did not itself reach the defect in the clean build.

Together, the evidence shows a complete behavioral path from information-seeking to hypothesis, experiment, execution, observation, and evidence-bounded conclusion.

## Not claimed by this run

This repository does not claim that:

- RED independently produced the verifier's reaching trigger;
- every RED investigation behaves this way;
- one run establishes a population-level reliability rate;
- the observed defect implies a specific exploitation primitive;
- “artificial brain” means biological equivalence; or
- this evidence establishes a world-first, state-of-the-art, or superiority claim over any named external system.

Those are different claims and would require different evidence.

The strength of this publication is that it does not need them.
