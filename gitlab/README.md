# GitLab

This directory contains public field records from RED-AVELA's authorized security research on GitLab.

RED-AVELA was given an objective and operated through its investigation process: inspecting the target, forming hypotheses, designing experiments, testing them in controlled environments, analyzing evidence, and producing reproducible findings.
